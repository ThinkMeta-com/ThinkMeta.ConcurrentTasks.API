Redistributable files
=====================

Of the files in this folder, only the core library itself may be redistributed with a program
that uses it, within the terms in LICENSE-Core.txt:

    bin\win-x64\ThinkMeta.ConcurrentTasks.Core.dll              Windows
    bin\linux-x64\libThinkMeta.ConcurrentTasks.Core.so.2        Linux, under the name it has here

Everything else here is for building and stays on the development machine:

    lib\win-x64\ThinkMeta.ConcurrentTasks.Core.lib       import library (Windows)
    Core.Release.win-x64.manifest.json                   version, source commit and checksum of the DLL
    Core.Release.linux-x64.manifest.json                 the same for the Linux library
    ThinkMeta.ConcurrentTasks.Core.props                 binds the core into a Visual Studio project

The same release build serves debug and release builds of your program: the DLL imports no C
runtime, the Linux library needs nothing but the C library (glibc 2.34 or newer).

Terms of use for the core are in LICENSE-Core.txt. Everything outside this folder - the header in
Include, the modules in Library, the CMake configuration in cmake, the tests and the samples - is
covered by the MIT license in the repository root.
